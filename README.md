### Hi, I'm JusticeFist

I build open-source tools around [Hermes Agent](https://hermes-agent.nousresearch.com/), mostly for using it from a phone.

**[AllFather](https://github.com/JusticeFist/alfatherapp)** is a native Android and Wear OS client for Hermes Agent: chat, voice, tasks, bots, Pulse and an assistant on the power button. Free and MIT.
